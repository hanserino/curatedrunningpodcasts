Thanks to Kineon for sponsoring this video! Get 10% off your order with code FLO at https://kineon.io/flo | Laura Green used to run every run as hard as she could. Now she's 40, has three kids, and has stopped chasing the times she ran at 18. We talk about handling a missed race goal, joining a run group when you feel intimidated, and why running gets more fun once you realize nobody is watching.
