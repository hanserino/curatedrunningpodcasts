About this episode

How To Write A Book About Running

Raziq Rauf is the author behind "This Is Running" a new book that comes out in a few short months. Raz is also the author behind Running Sucks on Substack, and in this episode we dig into the process of becoming a published author, along with all the necessary hurdles to get over the hurdles to making it happen.
