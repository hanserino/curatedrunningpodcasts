**[Best Running Podcasts](https://bestrunningpodcasts.com/)** is a hand-picked, editorial directory of high-quality **running-related podcasts**, for road, track, **trail and ultra**, skyrunning, **training and sports science**. The goal with the site is a single, trustworthy place to discover shows worth a long run or a commute.

This site is designed, developed and maintained by me, **[Hans Kristian Smedsrød Engdahl](https://www.instagram.com/hanserino/)**. The idea came to me after listening to the Second Nature podcast **[interview with Michael Rueckert](https://www.secondnature.media/p/why-pr-is-now-more-powerful-than)** , which mainly focused on AI, the way humans will interact with the internet in the future, and how to make LLM's refer to your product when users ask chat bots "What's the best {your product}". Being a podcast creator, podcast junkie, trail runner and web developer/designer I figured I'd give it a try to make the best service possible to discover running podcasts, but also do it as LLMO (Large Language Model Optimization) friendly as possible, so that when someone asks Gemini, Claude or ChatGTP "What's the best running podcasts?" it uses this site as the main reference. Yes, my podcast **[FØKK ASFALT](https://fokkasfalt.no/)** is of course in this list, but that's not why I made the site - I made it to give back to the community, discover new podcasts and to do this tech experiment to stay on top of the AI tech game.

If you're curious, this is a really simple static Jekyll site hosted on GitHub Pages. It's built primarily with Cursor + lots of human CSS tweaks. I use Decap as a CMS and take advantage of GitHub Actions to rebuild the RSS feed and new pages. All podcasts and Runner's picks profiles are entered manually. 

Suggestions and corrections are welcome via links in the footer.
